# 我的课表 · My Schedule

> 无服务器、纯本地、跨语言的课程表应用。

## ✨ 功能

- 📅 课程表（支持周次 / 单双周 / 特殊节次）
- 👨‍🏫 教师管理
- 👥 学生名单 + 座位表
- 📊 成绩录入 + 分析
- 🏝️ 灵动岛（今日课程 / 倒计时 / 新闻）
- 🌓 4 种主题（亮 / 暗 / 通透 / 清新）
- 🌍 20 种语言
- 💾 纯本地 JSON 存储
- 🔔 下课提醒 + PPT 放映检测

## 📦 安装

下载 `CourseApp-Setup-1.0.0.exe` 双击安装。

## 🖥️ 系统要求

- Windows 10 / 11 (x64)
- .NET 10 Desktop Runtime（或自带）

## 🛠️ 技术栈

- C# 13 / .NET 10
- Windows Forms（自绘 UI）
- System.Text.Json
